# Chassis 0.2.0

A new look that's all Chassis's own.

- Side rail navigation with the build on the bench, its price and score, and a one-click theme switcher.
- Spec-sheet styling: squared-off panels, numbered part slots with status stripes, LED-style meters, and monospaced numbers everywhere.
- New fonts: Chakra Petch, IBM Plex Sans and JetBrains Mono.
- The 3D build now sits on a gridded workbench mat instead of a turntable.
- New Aluminum theme replaces Frost.
