# Chassis 0.3.0

**Build from a picture.** Import a screenshot or photo of a parts list (PCPartPicker, a store page, Task Manager, a spec sheet), paste it, or drop it straight onto the 3D view. Windows reads the text on your PC, Chassis finds each part, you review the list, and it all goes inside the case you picked. One undo takes it back out.

- 348 parts, up from 66: 41 cases, 52 motherboards, 52 processors, 40 coolers, 37 memory kits, 45 graphics cards, 40 drives and 41 power supplies.
- Every part has a full spec sheet: clocks, cache, VRAM type, cable type, radiator support, endurance and more. The part in your build shows it in the list; hover any other part to see its sheet.
- E-ATX motherboards and 3.5-inch hard drives.
- The checks panel no longer says "Everything fits" on an empty build.
