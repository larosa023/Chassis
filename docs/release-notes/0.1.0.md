# Chassis 0.1.0

The first release.

- Build a PC in 3D: 8 part slots, 66 real parts, drag to turn, exploded view, RGB lighting and a spinning stand.
- Live compatibility checks for sockets, memory type, board size, GPU length, cooler height, radiator size, power supply size and wattage, and PCIe 5.0 SSD speed.
- Estimated benchmarks: frame rates in four kinds of games at 1080p, 1440p and 4K, CPU/GPU balance, CPU, memory, storage, power, temperatures, noise, value, and a Chassis Score.
- Garage with five starter builds, duplicate, delete, compare, and share codes.
- Five themes and a built-in updater.
